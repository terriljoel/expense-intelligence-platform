# Alembic migrations

The initial tables were created by
`database/migrations/001_initial_schema.sql`. The first Alembic revision records
that existing state without recreating or deleting those tables.

For the current local database, register the baseline once:

```cmd
cd apps\api
python -m alembic stamp 001_initial_schema
python -m alembic current
python -m alembic check
```

For a new empty database, first apply the initial SQL migration, then stamp the
baseline before applying later revisions:

```cmd
type database\migrations\001_initial_schema.sql | docker compose exec -T db psql -v ON_ERROR_STOP=1 -U expense_app -d expense_intelligence
cd apps\api
python -m alembic stamp 001_initial_schema
python -m alembic upgrade head
```

Create future revisions from `apps/api`:

```cmd
python -m alembic revision --autogenerate -m "describe the change"
python -m alembic upgrade head
```

Always review autogenerated migration files before applying them.
